# Legacy Next.js application

This directory contains the original Next.js and TypeScript implementation of the MKC ↔ EUS Delay Repay tracker.

It is retained for reference only. The supported application is the Python CLI in the repository root under `python/delayrepay/`. The GitHub Pages workflows in this directory are archived and do not run from here.

To inspect the old application independently, change into this directory and use its original Node and pnpm configuration.
